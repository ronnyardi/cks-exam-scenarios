# Introduction

In this scenario, you will faced a challenge regarding pod that should has an AppArmor profile applied to its container. But in reality, the pod is not running correctly. The objective of this scenario are:

1. Find the root cause of pod failed to run correctly due to misconfiguration in the AppArmor.
2. Fix and apply the correct AppArmor profile to the container of the pod.

By the end of this exercise, you will understand how to fix and apply the correct AppArmor profiles that can restrict specific behaviors in the container.
